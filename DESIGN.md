# Design system

## Visual world

JARVIS is a voice-first macOS command surface. A deep midnight field gives the speaking encounter quiet focus; cyan and violet signal color communicate state rather than decorate it. Familiar native navigation and controls keep the interface immediately operable.

## Signature move

The voice orb is the system’s single ambient motion: concentric signal fields expand gently while listening or speaking and rest when idle. It conveys status without requiring the user to read a dashboard.

## Type and density

Use native macOS typography for clarity. Large, compact titles establish hierarchy; supporting telemetry is concise and tabular where values are shown. Surface modules use generous outer spacing and restrained internal grouping.

## Color roles

- `background`: blue-black workspace ground.
- `surface`: elevated navy utility surfaces.
- `signal`: cyan for available / active system response.
- `violet`: depth within the voice encounter.
- semantic amber, green, and red: warnings, connected state, and failure only.

## Interaction

Voice is the default destination. Dashboard, chat, and settings remain standard navigable workspace modes. Motion honors Reduce Motion and never substitutes for status text.
